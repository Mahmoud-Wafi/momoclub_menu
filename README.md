# 🍽️ MOMO CLUB - Interactive QR Menu & Manager Dashboard
### تطبيق ومنيو إلكتروني تفاعلي متكامل مع لوحة إدارة خاصة للمدير

مشروع متكامل (Full-Stack) مصمم بأعلى معايير الويب العصرية:
- **Frontend**: واجهة تفاعلية فائقة السرعة مبنية بـ **React & Vite** بتصميم Dark Mode و Glassmorphism فخم باللغة العربية (RTL)، تتضمن:
  - منيو إلكتروني سريع متجاوب للهواتف والأجهزة اللوحية.
  - سلة مشتريات عائمة (Floating Cart) مع إرسال الطلبات مباشرة لواتساب المطعم.
  - **لوحة تحكم كاملة للمدير (Manager Dashboard)** مدمجة داخل التطبيق للتحكم الكامل في الأصناف والأقسام والأسعار وتوفر المنتجات.
- **Backend**: خادم متكامل مبني بـ **Django & Django REST Framework** مع قاعدة بيانات SQLite جاهزة تحتوي على جميع بيانات المنيو (11 قسم و 87 صنف) ولوحة إدارة Django Admin.

## 🚀 طريقة التشغيل المحلي (How to Run Locally)

لتشغيل المشروع، افتح نافذتي Terminal مستقلتين:

### 1️⃣ تشغيل الباك إند (Backend - Django)

```bash
# 1. الدخول إلى مجلد الباك إند
cd backend

# 2. تثبيت الحزم المطلوبة (مرة واحدة)
pip install -r requirements.txt

# 3. تشغيل سيرفر دجانجو
python3 manage.py runserver 0.0.0.0:8000
```

- **رابط الـ API:** [http://localhost:8000/api/](http://localhost:8000/api/)
- **رابط Django Admin:** [http://localhost:8000/admin/](http://localhost:8000/admin/)

---

### 2️⃣ تشغيل الفرونت إند (Frontend - React + Vite)

```bash
# 1. الدخول إلى مجلد الفرونت إند
cd frontend

# 2. تثبيت مكتبات Node.js (مرة واحدة)
npm install

# 3. تشغيل خادم التطوير
npm run dev
```

- **افتح المتصفح على:** [http://localhost:3000](http://localhost:3000)

---

## 🛑 إيقاف التشغيل (How to Stop Servers)

لإيقاف السيرفرات في أي وقت:
- اضغط `Ctrl + C` داخل كل Terminal مفتوح.
- أو عبر سطر الأوامر:
  ```bash
  pkill -f "runserver"
  pkill -f "vite"
  ```

## 🛠️ مميزات لوحة تحكم المدير (Manager Dashboard Features)

عند فتح الرابط [http://localhost:3000/manager](http://localhost:3000/manager) وإدخال (`admin` / `admin123@`):

1. **إحصائيات مباشرة (Real-time Stats):**
   - إجمالي عدد الأصناف في المنيو.
   - إجمالي عدد الأقسام الرئيسية.
   - عدد الأصناف المتاحة للطلب حالياً.
   - عدد الأصناف غير المتاحة (نفدت الكمية / Out of Stock).

2. **تبديل حالة التوفر بضغطة زر واحدة (Instant Availability Toggle):**
   - لكل صنف زر مباشر (`✅ متاح` / `❌ غير متاح`).
   - عند الضغط عليه، يتم تحديث حالة الصنف فوراً في قاعدة البيانات ويختفي أو يظهر تلقائياً للزبائن دون الحاجة لإعادة تحميل الصفحة.

3. **إضافة صنف جديد (Add New Item):**
   - تحديد القسم واسم الصنف والوصف.
   - دعم **السعر الموحد** أو **الأحجام المتعددة** (ربع / نص / كيلو / صغير / كبير) مع إمكانية إضافة وحذف أي عدد من الأحجام والأسعار بحرية.

4. **تعديل الأصناف (Edit Items):**
   - تعديل الاسم، السعر، القسم، الأحجام، والوصف وحفظ التعديلات فورياً.

5. **حذف الأصناف (Delete Items):**
   - نافذة تأكيد لمنع الحذف بالخطأ، مع حذف الصنف نهائياً من قاعدة البيانات.

6. **إدارة الأقسام (Categories Management):**
   - إضافة أقسام جديدة مع اختيار الأيقونة التعبيرية المناسبة (Emoji).
   - تعديل أسماء وأيقونات الأقسام القائمة وحذف الأقسام غير المطلوبة.

7. **معاينة المنيو كعميل:**
   - زر سريع `👁️ معاينة المنيو كعميل` للرجوع الفوري لشاشة الزبون واختبار المنيو.

## 🔗 مسارات الـ API الرئيسية (API Endpoints)

| المسار | الطريقة | الوصف |
|---|---|---|
| `/api/auth/login/` | `POST` | التحقق من بيانات المدير (`admin` / `admin123@`) |
| `/api/menu/` | `GET` | جلب المنيو الكامل مع الأقسام والأصناف التابعة |
| `/api/categories/` | `GET, POST` | عرض الأقسام أو إنشاء قسم جديد |
| `/api/categories/<id>/` | `GET, PUT, PATCH, DELETE` | تفاصيل، تعديل، أو حذف قسم |
| `/api/items/` | `GET, POST` | عرض الأصناف أو إضافة صنف جديد مع أحجامه |
| `/api/items/<id>/` | `GET, PUT, PATCH, DELETE` | تفاصيل، تعديل، أو حذف صنف وتغيير حالته |
| `/admin/` | `GET, POST` | لوحة إدارة Django القياسية |
